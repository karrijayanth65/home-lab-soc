# Visual production record

The installed Image skill guided the composition, restraint, consistent style and readable text. The built-in ImageGen tool generated the assets; no external paid API or CLI was used. These are fictional training interfaces, not screenshots from Wazuh or Windows. Every image carries a visible SIMULATION label.

All three are 16:9 with dark charcoal and navy panels, cyan accents, concise labels and generous margins. No vendor branding, fake hashes or alert identifiers are used. PNG originals are retained for readable repository display.
